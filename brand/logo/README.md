# ScribeWise logo

The mark is a fountain-pen nib whose slit turns into a check mark: the agent writes for you, and nothing goes out without your approval. The check is cut out of the nib (an SVG mask), so the background shows through it on any surface.

The wordmark is Literata (SIL Open Font License): “Scribe” upright 700, “Wise” italic 600, converted to outlines so it renders without the font.

## Files

| File | Use |
| --- | --- |
| `mark.svg` | Main mark, ink blue, on light backgrounds |
| `mark-ink.svg` | One-color mark (dark ink), for print and single-color use |
| `mark-inverse.svg` | Paper-colored mark for dark or blue backgrounds |
| `favicon.svg`, `favicon-32.png`, `favicon-48.png` | Small-size cut: wider nib and heavier check, for 16–48 px |
| `lockup.svg` | Mark + wordmark, color |
| `lockup-mono.svg` | Mark + wordmark, one color |
| `lockup-inverse.svg` | Mark + wordmark for dark backgrounds |
| `lockup-1200.png` | Raster lockup for docs and slides |
| `mark-512.png` | Raster mark, transparent background |
| `avatar.svg`, `telegram-avatar-640.png` | Telegram bot avatar (square; Telegram crops it to a circle) |
| `avatar-circle.svg` | Pre-cropped round avatar |
| `app-icon.svg`, `apple-touch-icon.png` | Square app icon, 180 px Apple touch icon |

## Rules

- Clear space around the mark: at least a quarter of its height on every side.
- Below 48 px, use the `favicon` cut instead of `mark`.
- Don’t recolor the check, rotate the mark, or set the wordmark in another font.
- Lockup minimum height: 24 px on screen.
