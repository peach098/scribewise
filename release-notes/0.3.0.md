## en

- In group chats, a draft now comes only when someone tags you or replies to your message. The "always draft" option for groups is gone; in /chats a group shows this rule instead.
- After the bot reads new messages in a chat or sends a reply you approved, the chat is marked unread again, so your chat list still shows where something happened. Opening the chat clears the mark. You can turn this off in /settings.
- New: work account mode. If this Telegram account is only for work, turn it on in /settings (or during setup): every private chat with a person becomes a work chat, including people who write to you for the first time. Bots and groups are not included; add groups in /chats. You can exclude any chat in /chats and turn the mode off any time.

## ru

- В групповых чатах черновик теперь появляется, только когда вас отметили или ответили на ваше сообщение. Настройки «черновик всегда» для групп больше нет: в /chats у группы теперь написано это правило.
- Когда бот прочитал новые сообщения в чате или отправил одобренный вами ответ, чат снова отмечается непрочитанным: в списке чатов видно, где что-то произошло. Отметка снимается, когда вы открываете чат. Выключить это можно в /settings.
- Новое: режим рабочего аккаунта. Если этот аккаунт Telegram только для работы, включите режим в /settings (или при настройке): каждый личный чат с человеком становится рабочим, в том числе с теми, кто напишет вам впервые. Боты и группы не входят, группы добавляются в /chats. Любой чат можно исключить в /chats, а режим — выключить в любой момент.
